\# Double-Ended Priority Queue

---

This small data structure was an attempt to learn priority queue design by building a container that could \*fetch both minimum and maximum priorities in O(1)\*. It's quite messy and after developing a working version I decided to test out newer C++20 and C++23 features on it so \*\*the version here is likely just broken\*\* but the fine-grained manipulation of a heap/tree structure was good practice.
